# Zhao et al. (2022): original-plant reproduction and predictor-identity audit

Implementation and reproducibility project for Kenshin Kotari. AI-assisted development and reporting. Original theory, models and figures are attributed to Yan Zhao, Huijun Gao, Shengyuan Xu and Yonggui Kao.

**Read [REPORT.md](REPORT.md) before interpreting the results.** The report separates the printed formulas, an explicitly disclosed traffic interpretation, a literal-composition diagnostic, numerical approximations and theorem applicability.

Source: *Predictor-feedback stabilization of two-input nonlinear systems with distinct and state-dependent input delays*, Automatica 144 (2022), 110479. DOI: 10.1016/j.automatica.2022.110479.

## Re-run

From this folder, with a CPU runtime (including free Google Colab):

```bash
pip install -r requirements.txt
python -m pytest -q test_audit.py
python audit.py --out regenerated-results
```

The runner executes all 18 declared traffic cases and the nine exact-trajectory diagnostics. It regenerates full trajectory CSVs, summaries, environment/source hashes and figures. No independently stabilized target generates the physical trajectory.

## Key boundary

Traffic `printed_product` uses the claimed identity to close the composed future term as g1(sigma2)=g2. It is **not** an unambiguous execution of all printed equations. The separate exact-trajectory diagnostic evaluates the literal composed term without that closure. The clock-consistent alternative is not an author-issued correction and is not a newly proved general stability theorem.

This publication includes the unchanged simulation source, unchanged tests, compact measured evidence and a text report. Full binary figures, full trajectories and digitized source curves are not committed in this compact publication; numerical outputs are regenerated by the runner. Original PDFs and author-generated figures are not redistributed. No author-code access, misconduct, MATLAB execution or GitHub CI success is claimed.
